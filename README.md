# Nineteenth-Century(1800s) Arabic Language Model

An independent, academically motivated project exploring how an existing language model can be adapted to nineteenth-century Arabic writing styles and historically situated perspectives, beliefs, and biases.

The project involves fine-tuning and deploying a model grounded in historical texts, while examining the limits of using language models to portray the past.

## Learning objectives

* Historical text collection and preprocessing
* Continued pretraining and supervised fine-tuning
* Model evaluation

## Research purpose and limitations

This project studies historical language and perspectives; it does not endorse prejudices or discriminatory views found in the source material or generated outputs.

The model is an experimental historical simulation. Its responses are generated interpretations, not authentic historical testimony. It may invent details, introduce modern ideas, or overgeneralize from a limited collection of authors. It should not be treated as representative of all nineteenth-century Arabic-speaking communities.

The project aims to document source provenance, reuse permissions, dataset selection, and preprocessing decisions. Any public demonstration will clearly identify the model as a simulation and explain its limitations.

## Initial corpus

* Book One (Published 1834)
* Approximately 62,000 cleaned words

* Book Two (Published 1895)

* Book Three (Published 1857)
* Approximately 102,506 cleaned words

* Newspaper One (Published 1884)
* Approximately 95,822 cleaned words


* Total approximately cleaned 308,201 words 

## Long-term goal

Expand the corpus and train a language-model from scratch as a separate phase.
